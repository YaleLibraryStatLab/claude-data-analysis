# They Do outputs

The ozone exercise is completed independently after the workshop. Create one
folder per participant and write only under your own folder.

Core artifacts:

- `brief.md`: the six-part prospective analysis brief;
- `audit.md`: evidence about coding, missingness, support, time order, and sample;
- `analysis.R` and `results.csv`: only after you approve an executable
  plan; and
- `handoff.md`: the plan decision, one check and its limit, unresolved choices,
  and a bounded claim or escalation.

Preserve a clean-session run log when code is executed. Incomplete analysis is
acceptable when the handoff names the blocker and expertise needed to continue.
