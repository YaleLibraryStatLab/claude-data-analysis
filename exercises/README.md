# Exercises

Analysis briefs and worksheets for the three cases.

| File | Used in | Purpose |
|---|---|---|
| `analysis-brief-template.md` | Prompt-writing segment | Blank six-part brief to fill in before asking an agent to analyze data |
| `i-do-kam-palmer-analysis-brief.md` | I Do | Completed brief used in the instructor demonstration |
| `we-do-salaries-analysis-brief.md` | We Do | Shared brief; each group completes the decision sections |
| `we-do-salaries-validation.md` | We Do | Code-reading and validation worksheet for the group's saved R script |
| `they-do-airquality-mission.md` | They Do | Independent ozone analysis to complete after the workshop |

In each case the agent audits the data and stops, the researcher approves an
evaluable plan, and only then does the agent fit anything.
